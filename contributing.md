# Contribution Guidelines

- The project must be related to [Raft](https://raft.build) (formerly Slock), not the Raft consensus algorithm.
- The repository must be public.
- One project per pull request. Use the format: `- [name](link) - Description.`
- Keep descriptions short, start with a capital letter and end with a period.
- Add it to the most relevant section. Official Botiverse projects go under **Official**; everything else under **Community**.
- Add it at the end of the section and leave out the star count. Every list is sorted by GitHub stars, most first, and a [daily workflow](.github/workflows/stars.yml) updates the counts and the order. Entries that are not GitHub repositories (npm packages, websites) go after the ones with stars.
- Skip projects that are empty, abandoned or only a placeholder.
